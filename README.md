# Noita Mods

A collection of personal mods for Noita.

## Start with Peace with Gods (`peace_at_start`)

This mod automatically grants the "You make peace with your gods" perk at the start of every run and removes it from the Holy Mountain perk pools to prevent duplication.

### Installation

1. Click the green **Code** button at the top of this GitHub repository and select **Download ZIP**.
2. Extract the downloaded ZIP file.
3. Open the extracted folder and locate the `peace_at_start` directory.
4. Move or copy the entire `peace_at_start` folder into your Noita installation directory's mods folder:
   `C:\Program Files (x86)\Steam\steamapps\common\Noita\mods\`

### How to Run

1. Launch **Noita**.
2. Click on **Mods** in the main menu.
3. Find **Start with Peace with Gods** in the list.
4. Click the checkbox next to it to enable it.
5. Start a **New Game**.
